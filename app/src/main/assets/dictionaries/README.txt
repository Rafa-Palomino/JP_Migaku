The importer prioritizes Spanish glosses and keeps English glosses as an
explicit fallback. KANJIDIC2 language fields are preserved using the same
Spanish-before-English resolution. Source files are bundled offline and are
not downloaded by the application.

jlpt-classifications.json.gz
Source: https://github.com/jkindrix/japanese-language-data
Upstream: Jonathan Waller JLPT Resources, stephenmk/yomitan-jlpt-vocab,
davidluzgouveia/kanji-data
License: CC BY-SA 4.0 redistribution, with CC BY 4.0 attribution for Waller
data and the applicable upstream license obligations

JLPT classifications are external community data and are not official JLPT
properties. They are stored separately from JMdict and KANJIDIC2. Vocabulary
classifications preserve the JMdict sequence, Japanese form, reading, and
level because one JMdict sequence can have multiple classified forms.
